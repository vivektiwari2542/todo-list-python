📝 To-Do List Application

A simple Command-Line To-Do List Application built using Python.
This project allows users to add, view, and delete tasks through an interactive menu.

🚀 Features

- ➕ Add new tasks
- 📋 View all tasks
- 🗑️ Delete tasks
- 🚪 Exit the application
- ✅ Simple and beginner-friendly command-line interface

🛠️ Technologies Used

- Python 3
- Python Lists
- Functions
- Loops
- Conditional Statements
- Exception Handling
- User Input

📂 Project Structure

todo-list-python/
│
├── todo.py
└── README.md

▶️ How to Run

1. Clone the repository

git clone https://github.com/vivektiwari2542/todo-list-python.git

2. Open the project folder

cd todo-list-python

3. Run the Python file

python todo.py

💻 How It Works

After running the program, you will see the following menu:

===== TO-DO LIST =====
1. Show Tasks
2. Add Task
3. Delete Task
4. Exit

Select an option according to your requirement.

Example

Enter your choice: 2

Enter a new task: Complete Python project

✅ Task added successfully!
